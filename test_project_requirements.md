## **🧩 Завдання: Ліди та дзвінки в CRM**

Потрібно реалізувати невеликий API-сервіс для роботи з лідами та дзвінками.

---

## **1️⃣ Сутності**

### **Manager**

* id  
* name

### **Lead**

* id  
* name  
* phone  
* status — `new`, `in_progress`, `won`, `lost`  
* manager\_id (nullable)

### **Call**

* id  
* lead\_id  
* duration (секунди)  
* result — `no_answer`, `callback_later`, `success`  
* created\_at

---

## **🔗 Зв’язки**

* Manager hasMany Leads  
* Lead belongsTo Manager  
* Lead hasMany Calls

---

## **2️⃣ API**

### **➕ Створення ліда**

`POST /api/leads`

---

### **📞 Додавання дзвінка до ліда**

`POST /api/leads/{lead}/calls`

У запиті передається:

* duration  
* result  
* manager\_id (хто здійснив дзвінок)

---

### **📋 Список лідів менеджера**

`GET /api/managers/{manager}/leads`

У відповіді для кожного ліда повернути:

* id  
* name  
* status  
* calls\_count  
* total\_call\_duration

---

## **3️⃣ Бізнес-логіка**

Логіка повинна виконуватись автоматично при створенні Call.

1. Якщо створено **перший дзвінок** для ліда →  
   статус змінюється з `new` → `in_progress`  
2. Якщо у ліда ще немає менеджера →  
   він автоматично закріплюється за менеджером, який створив дзвінок  
3. Якщо `result = success` →  
   статус ліда стає `won`  
4. Якщо **останні 3 дзвінки підряд** мають `result = no_answer` →  
   статус ліда стає `lost`

Статуси не повинні змінюватися напряму через API.
